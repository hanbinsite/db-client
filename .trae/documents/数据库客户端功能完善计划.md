# 数据库客户端功能完善计划

## 1. 数据导入功能

### 实现思路
- 在查询面板中添加导入按钮，支持从CSV、JSON、XLSX等格式导入数据
- 提供数据预览和字段映射功能，让用户可以选择目标表和字段映射关系
- 支持生成INSERT语句或直接导入数据到数据库

### 技术实现
- 使用HTML5 File API读取文件
- 集成xlsx库解析Excel文件
- 集成Papa Parse库解析CSV文件
- 使用JSON.parse解析JSON文件
- 实现数据映射界面，允许用户选择目标表和字段映射
- 生成并执行INSERT语句

### 文件修改
- 修改`src/renderer/components/sql-query/MySqlQueryPanel.tsx`
- 修改`src/renderer/components/sql-query/PostgreSqlQueryPanel.tsx`
- 添加新的导入组件`src/renderer/components/import/ImportDataModal.tsx`

## 2. 查询结果可视化

### 实现思路
- 在查询结果面板中添加图表切换按钮，支持多种图表类型
- 根据查询结果自动推荐合适的图表类型
- 提供图表配置选项，允许用户自定义图表样式和数据系列
- 支持图表导出功能

### 技术实现
- 使用现有的@ant-design/plots库实现图表
- 分析查询结果数据类型，推荐合适的图表类型
- 实现图表配置面板，允许用户自定义图表
- 支持图表导出为PNG、PDF等格式

### 文件修改
- 修改`src/renderer/components/sql-query/MySqlQueryPanel.tsx`
- 修改`src/renderer/components/sql-query/PostgreSqlQueryPanel.tsx`
- 添加新的图表组件`src/renderer/components/visualization/QueryResultChart.tsx`

## 3. 连接管理优化

### 实现思路
- 完善连接测试功能，提供详细的测试结果和错误信息
- 实现连接状态实时监控，显示连接池使用情况
- 添加连接池配置功能，允许用户调整连接池参数
- 提供连接配置导入导出功能

### 技术实现
- 在连接创建和编辑时添加详细的测试功能

- 实现连接池配置界面

### 文件修改

- 修改`src/renderer/components/connection/*ConnectionPanel.tsx`
- 添加连接状态监控组件`src/renderer/components/common/ConnectionStatusMonitor.tsx`

## 4. 查询历史记录

### 实现思路
- 保存用户执行过的查询语句，包括连接信息、执行时间、结果行数等
- 支持按数据库类型、连接、时间等筛选查询历史
- 提供查询语句的收藏功能
- 支持查询历史的导入导出

### 技术实现
- 使用IndexedDB保存查询历史
- 实现查询历史管理界面
- 添加查询语句的收藏功能
- 支持查询历史的导入导出

### 文件修改
- 修改`src/renderer/components/sql-query/MySqlQueryPanel.tsx`
- 修改`src/renderer/components/sql-query/PostgreSqlQueryPanel.tsx`
- 添加查询历史组件`src/renderer/components/sql-query/QueryHistory.tsx`

## 5. SQL格式化

### 实现思路
- 在查询编辑器中添加格式化按钮
- 实现SQL语句的自动格式化
- 支持自定义格式化规则
- 支持快捷键格式化

### 技术实现
- 集成sql-formatter库实现SQL格式化
- 在Monaco编辑器中添加格式化命令
- 实现格式化配置界面
- 支持快捷键格式化

### 文件修改
- 修改`src/renderer/components/sql-query/MySqlQueryPanel.tsx`
- 修改`src/renderer/components/sql-query/PostgreSqlQueryPanel.tsx`
- 添加SQL格式化服务`src/renderer/utils/sql-formatter.ts`

## 实施顺序

1. **SQL格式化** - 实现简单，用户体验提升明显
2. **查询历史记录** - 实现相对简单，对用户帮助大
3. **查询结果可视化** - 提升数据展示效果
4. **连接管理优化** - 提升连接可靠性和性能
5. **数据导入功能** - 实现复杂，但功能价值高

## 技术栈

- React 18
- Ant Design 5
- @ant-design/plots
- xlsx
- Papa Parse
- sql-formatter
- Monaco Editor

这个计划涵盖了所有要求的功能，并且按照实施难度和用户价值进行了排序。每个功能都有详细的实现思路和技术方案，可以确保顺利实施。
